# JSON Operations in JavaScript

Working with JSON (JavaScript Object Notation) in JavaScript primarily revolves around two built-in methods used for converting data back and forth.

## 1. `JSON.stringify()` 
Converts a JavaScript object, array, or value into a JSON-formatted string. This is essential when you need to send data to a web server, API, or save it in local storage.

### Example:
```javascript
const user = { 
  name: "Alice", 
  age: 25, 
  hobbies: ["reading", "coding"] 
};

// Convert object to JSON string
const jsonString = JSON.stringify(user);

console.log(typeof jsonString); // Output: string
console.log(jsonString); 
// Output: '{"name":"Alice","age":25,"hobbies":["reading","coding"]}'
```

## 2. `JSON.parse()`
Parses a JSON string and converts it back into a usable JavaScript object or array. You use this when receiving JSON data from a server or reading from local storage so your code can interact with its properties.

### Example:
```javascript
const jsonString = '{"name":"Bob","age":30,"isActive":true}';

// Convert JSON string to JavaScript object
const user = JSON.parse(jsonString);

console.log(typeof user); // Output: object
console.log(user.name);   // Output: Bob
console.log(user.age);    // Output: 30
```

---

## Best Practices

### Handling Errors with `try...catch`
Always wrap `JSON.parse()` in a `try...catch` block when handling data from external sources (like an API or user input). Parsing invalid JSON will throw a SyntaxError and can break your script.

```javascript
const malformedJson = '{"name": "Charlie", "age": 25'; // Missing closing brace

try {
  const data = JSON.parse(malformedJson);
  console.log(data);
} catch (error) {
  console.error("Failed to parse JSON:", error.message);
  // Output: Failed to parse JSON: Unexpected end of JSON input
}
```

### Formatting Output with `JSON.stringify()`
You can format the output of `JSON.stringify()` to be more readable (pretty-print) by using its optional parameters: a replacer function (usually `null` if not used) and a space count (for indentation).

```javascript
const user = { name: "Dave", role: "Admin" };

// Pretty print with 2 spaces of indentation
const prettyJson = JSON.stringify(user, null, 2);

console.log(prettyJson);
/* Output:
{
  "name": "Dave",
  "role": "Admin"
}
*/
```

# Lecture Notes: Client-Side Storage in JavaScript (Cookies vs LocalStorage)

In modern web development, it is often necessary to store data on the user's browser (client-side) to remember user preferences, maintain login sessions, or save cart data. The two most common ways to achieve this in JavaScript are **Cookies** and **LocalStorage**.

---

## 1. Cookies

Cookies are small pieces of data (usually up to 4KB) stored as text on the user's computer. They were originally designed for server-side reading, meaning they are automatically sent back and forth between the client and the server with every HTTP request.

### Key Characteristics of Cookies:
*   **Capacity:** Very small (~4KB per cookie).
*   **Expiration:** Can be set to expire at a specific date/time. If no expiration is set, they become "session cookies" and are deleted when the browser closes.
*   **Performance:** Sent with *every* HTTP request, which can slow down network performance if a lot of data is stored.
*   **Security:** Susceptible to Cross-Site Scripting (XSS) and Cross-Site Request Forgery (CSRF). 

### JavaScript Operations for Cookies

In JavaScript, cookies are accessed and manipulated via the `document.cookie` property. Note that `document.cookie` acts like a string, but assigning to it only updates or adds a cookie, it doesn't overwrite all existing cookies.

#### Example Script: Working with Cookies

```javascript
// 1. Setting a Cookie
// Basic cookie
document.cookie = "username=JohnDoe";

// Setting a cookie with an expiration date and path
const expirationDate = new Date();
expirationDate.setTime(expirationDate.getTime() + (7 * 24 * 60 * 60 * 1000)); // 7 days from now
document.cookie = `theme=dark; expires=${expirationDate.toUTCString()}; path=/`;

// 2. Reading a Cookie
// document.cookie returns all cookies as a single semicolon-separated string: "key1=value1; key2=value2"
console.log("All Cookies:", document.cookie);

// Function to get a specific cookie by name
function getCookie(name) {
  const cookieString = document.cookie;
  const cookies = cookieString.split('; ');
  for (let cookie of cookies) {
    const [key, value] = cookie.split('=');
    if (key === name) {
      return decodeURIComponent(value);
    }
  }
  return null;
}
console.log("Theme Cookie:", getCookie('theme'));

// 3. Deleting a Cookie
// To delete a cookie, you set its expiration date to a time in the past.
document.cookie = "username=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/;";
```

---

## 2. LocalStorage

`LocalStorage` is a part of the Web Storage API introduced in HTML5. It provides a much simpler and cleaner way to store key/value pairs in a web browser. 

### Key Characteristics of LocalStorage:
*   **Capacity:** Much larger than cookies (typically around 5MB to 10MB per domain).
*   **Expiration:** Data stored in LocalStorage **does not expire**. It remains until explicitly cleared by the user (clearing browser cache) or deleted via JavaScript.
*   **Performance:** Data is strictly stored on the client and is *not* sent to the server with HTTP requests, saving bandwidth.
*   **Data Type:** Only stores strings. If you want to store arrays or objects, you must use `JSON.stringify()` and `JSON.parse()`.

### JavaScript Operations for LocalStorage

LocalStorage provides a simple, synchronous API with clear methods: `setItem()`, `getItem()`, `removeItem()`, and `clear()`.

#### Example Script: Working with LocalStorage

```javascript
// 1. Setting Data in LocalStorage
localStorage.setItem("username", "JaneDoe");
localStorage.setItem("theme", "light");

// Storing an object (Must convert to JSON string first)
const userSettings = { volume: 80, notifications: true };
localStorage.setItem("settings", JSON.stringify(userSettings));

// 2. Reading Data from LocalStorage
const savedUser = localStorage.getItem("username");
console.log("Username from LocalStorage:", savedUser);

// Retrieving and parsing an object
const savedSettingsString = localStorage.getItem("settings");
if (savedSettingsString) {
  const parsedSettings = JSON.parse(savedSettingsString);
  console.log("Volume Setting:", parsedSettings.volume);
}

// 3. Removing Data from LocalStorage
// Remove a specific item
localStorage.removeItem("theme");

// 4. Clearing all LocalStorage for the domain
// localStorage.clear(); // Uncomment to clear everything
```

---

## Summary Comparison

| Feature | Cookies | LocalStorage |
| :--- | :--- | :--- |
| **Capacity** | ~4 KB | ~5 MB |
| **Expiration** | Set manually (or expires on session end) | Never (until explicitly deleted) |
| **Sent to Server** | Yes, automatically with every HTTP request | No, strictly client-side |
| **Access** | `document.cookie` (Cumbersome string manipulation) | `window.localStorage` (Clean API) |
| **Best For** | Server-side authentication (session IDs, JWTs) | Client-side preferences, offline data caching |
