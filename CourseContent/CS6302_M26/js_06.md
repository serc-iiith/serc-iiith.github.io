# BOM

**BOM** in JavaScript stands for **Browser Object Model**, which provides a way for JavaScript to interact with the web browser beyond just the content of the webpage.

## What is BOM?

- BOM is a collection of objects supplied by web browsers that let scripts control browser features like windows, navigation, history, screen, and location.
- BOM is not formally standardized, unlike the DOM (Document Object Model), but most modern browsers implement similar BOM APIs.
- The BOM lets JavaScript "talk to" the browser, allowing actions like opening new windows/tabs, navigating browser history, accessing the URL, and more.

## Core BOM Objects and Examples

## Window Object

- Root of the BOM hierarchy; represents the browser window or tab.
- All global variables and functions are properties/methods of the window object.
- Example:
    
    `jswindow.alert('Hello, World!');
    let width = window.innerWidth;
    let height = window.innerHeight;`
    
- Open/close a window:
    
    `jswindow.open('https://example.com');
    window.close();`
    

## Navigator Object

- Provides information about the browser and operating system.
- Example:
    
    `jsconsole.log(navigator.userAgent); *// e.g. details on Chrome/Firefox/Safari*`
    

## Location Object

- Manages the current URL; allows you to retrieve and change the address.
- Example:
    
    `jsconsole.log(location.href); *// Prints current URL*
    location.reload(); *// Reloads the page*`
    

## Screen Object

- Provides details about the user's physical screen.
- Example:
    
    `jsconsole.log(screen.width, screen.height);`
    

## History Object

- Lets you interact with the browser's session history (back, forward, etc.).
- Example:
    
    `jshistory.back();    *// Go one step back*
    history.forward(); *// Go one step forward*`
    

## Key Points

- BOM enables control over **browser** level features, not just the content itself
- The DOM handles the document structure and content, while BOM handles navigation, window management, and user information.
